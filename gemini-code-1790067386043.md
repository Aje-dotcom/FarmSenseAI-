# 🌾 FarmSense AI: Hyperlocal Multilingual Crop Disease & Advisory Assistant

[![MVP Status](https://img.shields.io/badge/MVP-Ready-success)](#) [![3MTT x MIT](https://img.shields.io/badge/Challenge-3MTT%20x%20MIT%20Open%20Learning-blue)](#)

FarmSense AI is an offline-first, multilingual AI diagnostic tool and conversational advisor built to help rural smallholder farmers combat crop diseases, optimize yields, and manage edge IoT farming hardware.

## 🎯 Problem Statement
Smallholder farmers across rural Nigeria face up to 30–40% annual crop losses due to unmanaged diseases and delayed pest identification. Existing diagnostic tools demand high-bandwidth internet and are strictly English-based, excluding non-literate and indigenous language-speaking communities. 

## 💡 The Solution
FarmSense AI bridges this digital divide through a multimodal, agentic architecture:
* **Visual Diagnostics:** Edge-capable computer vision to diagnose leaf pathologies via smartphone cameras.
* **Multilingual Voice Advisory:** RAG-powered, localized farming advice in Hausa, Yoruba, Igbo, and Pidgin.
* **IoT Telemetry (In Development):** Integration with field sensors to correlate ambient conditions with visual crop data, triggering explainable AI (XAI) shut-offs for irrigation systems.

## 🏗️ Architecture & Tech Stack
* **Backend:** Python, Flask, SQLite (for edge analytics)
* **AI/ML:** Quantized CNN for vision, LangChain for agentic orchestration
* **Frontend:** HTML5, JS (Native BarcodeDetector API for IoT QR pairing)

## 🚀 Quick Start (Local Deployment)
1. Clone the repository: `git clone https://github.com/yourusername/FarmSense-AI.git`
2. Navigate to the backend: `cd FarmSense-AI/backend`
3. Install dependencies: `pip install -r ../requirements.txt`
4. Run the orchestration server: `python app.py`

## 🗺️ Roadmap: Agritech Edge Builds
While the diagnostic app and analytics dashboard represent the current MVP, the following components are staged in the `edge_iot_pending/` directory for our V2 rollout:
* **MQTT-SN Telemetry Nodes:** Low-power C++ scripts for soil moisture and NPK edge sensors.
* **Automated Actuator Relays:** Hardware integration for automated misting and irrigation, governed by our XAI Event Monitor.

## ⚖️ Responsible AI
This project ensures **Fairness** by training on diverse lighting conditions and crop stages, **Inclusivity** via indigenous voice interfaces, and **Transparency** by clearly outputting confidence scores and relying on verified agricultural extension databases for local remedies.
